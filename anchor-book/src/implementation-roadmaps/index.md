# Implementation Roadmaps

Implementation roadmaps turn a sufficiently clear design into agreed work: the
outcomes to build, their dependencies, and how completion will be demonstrated.
The AI Working Contract (`anchorbook contract`, “Work with the engineer”) defines
how agents propose roadmaps and when work may begin. Milestones follow the
engine's roadmap format; see [Working on Symposium](../working-on-symposium.md#book-sources-and-authoring-references).
